These scripts configure common AI coding tools to use OpenSand.

Public URLs after publishing:

- `https://opensand.ai/scripts/claude-cli-setup.sh`
- `https://opensand.ai/scripts/claude-cli-setup.ps1`
- `https://opensand.ai/scripts/codex-cli-setup.sh`
- `https://opensand.ai/scripts/codex-cli-setup.ps1`
- `https://opensand.ai/scripts/factory-droid-cli-setup.sh`
- `https://opensand.ai/scripts/factory-droid-cli-setup.ps1`

The scripts intentionally use OpenSand-owned domains and environment variables.
They only configure local tools to call OpenSand endpoints.
