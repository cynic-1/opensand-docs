# 用量日志

用量日志用于排查请求问题和分析成本。

## 重点看什么

- 请求时间：定位问题发生时间。
- 模型：确认是否调用了预期模型。
- 状态码：判断成功、鉴权失败、限流或模型错误。
- Token / 消耗：分析成本来源。

## 常见排查

| 现象 | 检查 |
|---|---|
| 401 | API Key 是否正确 |
| 429 | 是否触发频率限制或额度限制 |
| 模型不存在 | 模型 ID 是否拼写正确 |
| 成本异常 | 是否传入过长上下文或开启高成本模型 |

## 怎么读一条日志

一条日志通常能回答四个问题：

1. 谁调用的：看 API Key 或用户信息。
2. 调了什么：看模型和接口路径。
3. 成功没有：看状态码和错误信息。
4. 花了多少：看 Token、图片/视频参数和消耗。

当用户反馈“工具不能用”时，先让他在工具里发起一次请求，再刷新日志。如果日志里没有记录，通常是客户端没有真正请求到 OpenSand。
