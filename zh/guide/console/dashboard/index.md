# 控制台概览

控制台用于查看账户状态、模型可用性、近期用量和请求情况。

## 你可以在这里做什么

- 查看账户余额或额度。
- 查看近期调用趋势。
- 快速进入令牌、日志、模型和 Playground。
- 判断问题是 Key、模型、额度还是请求参数导致。

如果刚开始使用，建议先创建 API Key，再到 Playground 发送一条测试消息。

## 新手推荐流程

1. 先看余额或额度是否正常。
2. 创建 API Key。
3. 到 Playground 选择一个模型测试。
4. 测试成功后，再复制同样的模型 ID 到客户端。
5. 如果客户端失败，到用量日志里看有没有请求记录。
