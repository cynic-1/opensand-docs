# OpenSand 是什么

OpenSand 是一个统一的 AI API 网关。它把不同模型和供应商聚合到同一个入口，开发者只需要维护一套 API Key、Base URL 和调用方式。

## 适合谁

- 想快速接入多模型能力的开发者。
- 需要统一管理 API Key、用量和模型权限的团队。
- 想把 Claude Code、Codex CLI、Cherry Studio、OpenClaw 等工具接到同一平台的用户。

## 核心价值

- 统一接口：减少不同供应商之间的适配成本。
- 统一管理：集中管理 Key、模型、用量和日志。
- 工具兼容：兼容 OpenAI API 和常见 AI 工具。
