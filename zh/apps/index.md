# 应用接入

只要工具支持 OpenAI Compatible、Custom Endpoint 或自定义 Base URL，通常都可以接入 OpenSand。

## 通用配置

| 字段 | 填写 |
|---|---|
| Base URL | `https://opensand.ai/v1` |
| API Key | OpenSand 控制台创建的 Key |
| Model | 控制台或 `/v1/models` 返回的模型 ID |
