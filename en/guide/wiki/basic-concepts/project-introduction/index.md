# What Is OpenSand?

OpenSand is a unified AI API gateway. It aggregates different models and providers behind one entry point, so developers maintain one API key, one Base URL, and one integration pattern.

## Who It Is For

- Developers who want to quickly integrate multiple model families.
- Teams that need centralized API key, usage, and model access management.
- Users who want Claude Code, Codex CLI, Cherry Studio, OpenClaw, and other tools connected to one platform.

## Core Value

- Unified interface: less provider-specific integration work.
- Centralized management: keys, models, usage, and logs in one place.
- Tool compatibility: works with OpenAI APIs and common AI tools.
