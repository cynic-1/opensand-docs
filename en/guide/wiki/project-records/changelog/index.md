# Project Records

Project records are maintenance notes for maintainers. Users care about the result; maintainers also need context and impact.

## Suggested Notes

- Why the change was made.
- Which models, APIs, or console pages are affected.
- Whether users need to migrate.
- Whether screenshots or scripts need updates.
