# Playground

Playground lets you test models in the console before writing code.

## Use It To

- Verify that an API key and model work.
- Compare model quality.
- Debug prompts and parameters.
- Confirm a model ID before configuring a client.

After a test succeeds, use the same model name in your client or API request.

## Testing Tips

- Start with one simple message so prompt issues and API issues are not mixed together.
- Disable streaming, tools, browsing, and other advanced features first.
- If one model fails, try a basic chat model to identify whether the issue is model-specific.
- Copy the model ID that works in Playground directly into your client.
