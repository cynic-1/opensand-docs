# Dashboard

The dashboard helps you review account status, model availability, recent usage, and request health.

## What You Can Do

- Check balance or quota.
- Review recent request trends.
- Jump to tokens, logs, models, and Playground.
- Determine whether an issue is caused by the key, model, quota, or request parameters.

If you are new, create an API key first, then send a test message in Playground.

## Recommended Beginner Flow

1. Check whether balance or quota is available.
2. Create an API key.
3. Test a model in Playground.
4. Copy the same model ID into your client after the test works.
5. If the client fails, check usage logs for request records.
