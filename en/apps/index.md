# App Integrations

Any tool that supports OpenAI Compatible, Custom Endpoint, or custom Base URL can usually connect to OpenSand.

## Common Settings

| Field | Value |
|---|---|
| Base URL | `https://opensand.ai/v1` |
| API Key | A key created in the OpenSand console |
| Model | A model ID returned by the console or `/v1/models` |

## Recommended Apps

| App | Best For |
|---|---|
| [Cherry Studio](/en/docs/apps/cherry-studio) | Desktop chat and model comparison |
| [Claude Code](/en/docs/apps/claude-code) | Terminal coding with Claude protocol tools |
| [Codex CLI](/en/docs/apps/codex-cli) | Command-line development agent |
| [OpenCode](/en/docs/apps/opencode) | Terminal coding agent |
| [OpenClaw](/en/docs/apps/openclaw) | Self-hosted multi-channel agents |
| [AionUi](/en/docs/apps/aionui) | Local AI workspace |
