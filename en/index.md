# OpenSand Docs

OpenSand is a unified AI model gateway. Use one API key and one Base URL for chat, embeddings, images, video, and common developer tools.

## Start Here

1. [Quick Start](/en/docs/guide/quick-start): create an API key and make your first API call.
2. [Pricing and Usage](/en/docs/guide/pricing): understand balance, usage, and model cost.
3. [API Docs](/en/docs/api): review OpenAI-compatible and model APIs.
4. [App Integrations](/en/docs/apps): configure Claude Code, Codex CLI, Cherry Studio, OpenClaw, and more.

## Most Common Settings

| Setting | Value |
|---|---|
| API Base URL | `https://opensand.ai/v1` |
| API Key | Create it in the OpenSand console |
| Model name | Query the console or `/v1/models` |

## Common Questions

- Which URL should I use? Most OpenAI-compatible tools use `https://opensand.ai/v1`.
- Which model name should I use? Call `GET /v1/models`.
- A request fails? Check the API key first, then the model name and account quota.
